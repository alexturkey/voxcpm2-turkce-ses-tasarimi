# voxcpm2-turkce-ses-tasarimi

**ออกแบบเสียงภาษาตุรกีด้วย VoxCPM2 บน GPU 4 GB** อธิบายเสียงที่ต้องการเป็นภาษาอังกฤษ ให้โมเดลสร้างเสียงนั้นขึ้นมา เลือกตัวเลือกที่ชอบ
แล้วใช้เสียงนั้นอ่านข้อความภาษาตุรกีอะไรก็ได้ ในชุดนี้มีตัวติดตั้งที่ใช้คำสั่งเดียว เอนจิน
[audio.cpp](https://github.com/0xShug0/audio.cpp) ที่แพตช์ให้รันบน GTX 1050 Ti (4 GB) ได้ เว็บ UI ขนาดเล็กที่รันในเครื่อง และเสียงสังเคราะห์สำเร็จรูป
สิบสี่เสียง ได้แก่ เสียงภาษาตุรกีเจ็ดเสียง และผู้บรรยายเจ้าของภาษาอีกเจ็ดเสียงในภาษาอังกฤษ ฝรั่งเศส เยอรมัน สเปน
รัสเซีย จีน และญี่ปุ่น

- อ่านได้ 30 ภาษา และหน้าจอใช้งานก็มีให้เลือก 30 ภาษาเช่นกัน
- เสียงสำเร็จรูป 14 เสียง: ภาษาตุรกี 7 เสียง และภาษาอังกฤษ ฝรั่งเศส เยอรมัน สเปน รัสเซีย จีน ญี่ปุ่น ภาษาละ 1 เสียง
- เว็บ UI (v0.2.0): การ์ดตัวเลือกทุกใบมีสองเสียง คือเสียงต้นแบบดิบ และเสียงที่คุณจะได้ยินตลอดไป มีรายการ
  อ่านพร้อมเมนูเสียง เปลี่ยนชื่อ ซ่อน หรือลบเสียงได้ และบันทึกข้อความที่อ่านเป็นฉบับร่างได้ ดู "เว็บ UI" ในหัวข้อ "การใช้งาน"

[ทำอย่างไรให้พอดีกับ 4 GB](docs/4gb.md) · [Ubuntu / Linux](docs/linux.md) · [macOS](docs/mac.md) · [คู่มือติดตั้งสำหรับเอเจนต์ AI](AGENTS.md) · [การใช้งานอย่างรับผิดชอบ](ETHICS.md)

> เสียงที่มาพร้อมชุดนี้เป็นเสียงสังเคราะห์ทั้งหมด ออกแบบจากคำอธิบายที่เป็นข้อความ ส่วนโคลนเสียงใช้ได้เฉพาะกับเสียงของคุณเอง
> หรือเสียงที่ได้รับอนุญาตอย่างชัดแจ้งจากเจ้าของเสียงเท่านั้น และหน้าจอจะขอให้คุณยืนยันการอนุญาตนั้น ห้ามใช้เพื่อแอบอ้างเป็นผู้อื่น
> ฉ้อโกง หรือหลอกลวง ระบุทุกครั้งว่าสิ่งที่สร้างขึ้นเป็นผลงานจาก AI ดู [ETHICS.md](ETHICS.md)

## 30 ภาษา

เราทำวิดีโอสารคดีคัปปาโดเกียหนึ่งเรื่องใน 8 ภาษา ได้แก่ ตุรกี อังกฤษ ฝรั่งเศส เยอรมัน สเปน รัสเซีย จีน
และญี่ปุ่น แต่ละภาษามี**ผู้บรรยายเจ้าของภาษา**ของตัวเอง ซึ่งออกแบบด้วย VoxCPM2 จากคำอธิบายภาษาอังกฤษ ทั้งหมด
สร้างขึ้นในเครื่องล้วน ๆ บน GTX 1050 Ti 4 GB ด้วยคุณภาพคงที่เท่ากันทุกภาษา (16 สเต็ป, cfg 2.0) ผู้บรรยายทั้งเจ็ด

**ทำไมต้องอ่านทีละประโยค** VoxCPM2 ไม่เสถียรเมื่อสร้างเสียงยาวในครั้งเดียว (ราว ๆ เกิน 30 วินาที) จังหวะ
จะเร็วขึ้นเรื่อย ๆ และเสียงอาจเพี้ยนไป ในโปรเจกต์นี้เสียงจะถูกคงไว้ด้วยไฟล์เสียงอ้างอิงและซีดที่ตายตัว ส่วนข้อความยาวจะ
อ่านทีละประโยคต่อบรรทัด น้ำเสียงและสไตล์จึงเหมือนเดิมตั้งแต่ประโยคแรกจนถึงประโยคสุดท้าย ภาษาอื่นนอกจาก
ภาษาตุรกีจะไม่ใช้พจนานุกรมการออกเสียงภาษาตุรกี ทั้ง 30 ภาษาที่ VoxCPM2 รองรับผ่านการทดสอบแล้วและใช้งานได้ สำหรับภาษาที่ไม่มีเสียงสำเร็จรูป ให้ใช้
`--dil <code>` คำสั่งของแต่ละภาษาและบทเรียนที่เราได้เรียนรู้:
[docs/cok_dilli.md](docs/cok_dilli.md) สกิล Claude Code สำหรับขั้นตอนการออกแบบทั้งหมด:
[.claude/skills/ses-tasarimi/SKILL.md](.claude/skills/ses-tasarimi/SKILL.md)

**พรอมต์ตัวอย่าง 144 แบบให้เริ่มต้นได้ทันที** มี 18 บทบาท (ผู้บรรยายสารคดี ผู้ประกาศข่าว เสียงโฆษณา หนังสือเสียง
คุณยายเล่านิทาน พิธีกรพอดแคสต์ ครู ตัวอย่างภาพยนตร์ ผู้นำทำสมาธิ ผู้บรรยายกีฬา และอื่น ๆ ทั้งเสียงชายและ
หญิง) ในแต่ละภาษาจากทั้ง 8 ภาษา พรอมต์เป็นภาษาอังกฤษ ระบุสัญชาติและสำเนียงเจ้าของภาษาของผู้พูด และมีข้อความที่ใช้
อ่านตอนสร้างเสียงมาให้ด้วย เป็นภาษานั้นและเข้ากับบทบาท เลือกมาหนึ่งแบบ ฟังตัวเลือกต่าง ๆ แล้วเก็บแบบที่ชอบไว้:

## เริ่มต้นอย่างรวดเร็ว (Windows, 3 ขั้นตอน)

1. **ดาวน์โหลด** โค้ด: [voxcpm2-turkce-ses-tasarimi-main.zip](https://github.com/alexturkey/voxcpm2-turkce-ses-tasarimi/archive/refs/heads/main.zip)
   ส่วนแพ็กเกจเอนจินสำเร็จรูปสำหรับการ์ดจอของคุณ ตัวติดตั้งจะดาวน์โหลดให้ในขั้นตอนที่ 3:
   NVIDIA → [แพ็กเกจ CUDA](https://github.com/alexturkey/voxcpm2-turkce-ses-tasarimi/releases/download/v0.3.2/voxcpm2-turkce-ses-tasarimi-motor-v0.3.2-win64-cuda12.8.zip),
   AMD / Intel → [แพ็กเกจ Vulkan แบบทดลอง](https://github.com/alexturkey/voxcpm2-turkce-ses-tasarimi/releases/download/v0.3.2/voxcpm2-turkce-ses-tasarimi-motor-v0.3.2-win64-vulkan.zip)
   (ดาวน์โหลดไว้แล้ว? เพิ่ม `-HazirZip <path to the zip>` ต่อท้ายคำสั่งด้านล่าง)
2. **แตกไฟล์** zip เปิดโฟลเดอร์ `voxcpm2-turkce-ses-tasarimi-main` พิมพ์ `powershell` ในแถบที่อยู่ของ File Explorer
   แล้วกด Enter
3. **รัน** ตัวติดตั้ง (ต้องใช้ Python 3.10-3.13 แบบ 64 บิต และไดรเวอร์ NVIDIA ≥ 570 สำหรับ CUDA) จากนั้นดับเบิลคลิก **`baslat.bat`**:
   ```powershell
   powershell -NoProfile -ExecutionPolicy Bypass -File scripts\kur.ps1 -Kok C:\vox
   ```
   AMD / Intel: เพิ่ม `-Vulkan` ต่อท้าย หน้าจอจะเปิดที่ http://127.0.0.1:8765/

zip ของเอนจินไม่ใช่แอปที่รันได้เดี่ยว ๆ (ไฟล์ exe ข้างในต้องใช้โมเดลและ DLL ที่ตัวติดตั้งเตรียมให้) รายละเอียด รายชื่อ
GPU และปัญหาที่พบบ่อย: ดู "ติดตั้งอย่างรวดเร็ว" ด้านล่าง

## Ubuntu / Linux (NVIDIA CUDA, ทดลอง)

สร้างเอนจินที่แพตช์แล้วด้วย `bash scripts/kur-linux.sh` หรือใช้ `Dockerfile.linux` เพื่อสร้างและรันใน
สภาพแวดล้อม Ubuntu 24.04 / CUDA 12.8.1 ต้องมี GPU ของ NVIDIA และไดรเวอร์ที่เข้ากันได้ ส่วนตัวติดตั้งแบบเนทีฟยัง
ต้องใช้ CUDA toolkit และ Python 3.10-3.13 ด้วย หน้าจอจะรับการเชื่อมต่อเฉพาะจาก loopback (ในเครื่อง) เท่านั้น แม้บนเซิร์ฟเวอร์ระยะไกล (ใช้ SSH forwarding)
สิ่งที่ต้องมีก่อน คำสั่ง การเลือกสถาปัตยกรรม และขอบเขตการตรวจสอบ: [docs/linux.md](docs/linux.md)

## เริ่มต้นอย่างรวดเร็ว (macOS, Apple Silicon)

ต้องมี Xcode Command Line Tools (`xcode-select --install`) และ [Homebrew](https://brew.sh):
```bash
brew install cmake python@3.12
git clone https://github.com/alexturkey/voxcpm2-turkce-ses-tasarimi.git
cd voxcpm2-turkce-ses-tasarimi
bash scripts/kur.sh
```
ตัวติดตั้งจะดาวน์โหลดโมเดล สร้างเอนจินที่แพตช์แล้วด้วย Metal (~1 นาที) และตั้งค่าทุกอย่างไว้ใต้ `~/vox`
จากนั้นดับเบิลคลิก **`baslat.command`** บน MacBook Air M4 16 GB: ใช้เวลาประมวลผล ~2 วินาทีต่อเสียงพูด 1 วินาที ซีดเดียวกันให้
เสียงที่เหมือนกันทุกไบต์ ใช้ RAM สูงสุด ~5.3 GB และไม่มีการลดความเร็วจากความร้อนตลอดการอ่านต่อเนื่อง 12 นาที รายละเอียดและ
ผลการวัด: [docs/mac.md](docs/mac.md)

**แอป Mac แบบเนทีฟ (ไม่ต้องใช้ Python, Homebrew หรือ Terminal):** [macos/README.md](macos/README.md) แอปนี้รวม
เอนจินที่แพตช์แล้วตัวเดียวกันไว้ และจะดาวน์โหลดโมเดลเมื่อเปิดครั้งแรก ตอนนี้ยังต้องสร้างจากซอร์สด้วย Xcode

## หลักการทำงาน

1. **การออกแบบเสียง** *คำอธิบายเสียง* ภาษาอังกฤษ + *ข้อความที่อ่านตอนสร้างเสียง* (ในภาษาของเสียงนั้น) + จำนวน
   ตัวเลือก แต่ละตัวเลือกได้ซีดของตัวเอง เอนจินรับ `(description)text` แล้วส่งไฟล์เสียงต้นแบบกลับมา
   หนึ่งไฟล์ต่อหนึ่งซีด ข้อความนี้เป็นตัวอย่างสั้น ๆ ไว้ทำความรู้จักเสียง: 1-3 ประโยค ยาวไม่เกิน ~30 วินาที (หน้าจอจะแสดง
   เวลาโดยประมาณ และจะไม่เริ่มถ้าเกิน 33 วินาที) ข้อความยาวให้ไปทำในขั้นตอนที่ 2
2. **การอ่านโดยใช้เสียงอ้างอิง** ไฟล์เสียงต้นแบบจะถูกส่งเข้าอินพุตของเอนจิน**ทั้งสองช่อง** (`audio` และ `voice_ref`)
   พร้อมข้อความถอดเสียงของมัน (`reference_text`) และข้อความใหม่ที่จะอ่าน โดยใช้ซีดเดิม เสียงถูกคงไว้ด้วย
   ไฟล์เสียง ไม่ใช่ด้วยคำอธิบาย จึงไม่เพี้ยนไปเมื่อเปลี่ยนข้อความ ข้อความจะถูกอ่านทีละประโยค
3. คุณภาพคงที่: 16 diffusion step, CFG 2.0 ซีดไม่ใช่ปุ่มปรับคุณภาพ
4. **เวลาของแต่ละคำ และเสียงเหมือนเดิมทุกครั้ง** ขณะอ่าน เอนจินจะบอกเองว่าแต่ละคำเริ่มและจบตรงไหน (แพตช์ 0002 ไม่ต้องใช้โมเดลเพิ่ม) เวลาเขียนลงใน `kelimeler.json` และตัดบรรทัดให้ช่วงเว้นระหว่างบรรทัดเท่ากับค่าเว้นจังหวะ ความแม่นยำเทียบกับ CTC forced alignment (ถือว่า CTC = 100%): 89.66% (ภาษาตุรกี 12 เสียง; ค่า `kelime_zamani` เปิดเป็นค่าเริ่มต้น) เมื่อใช้แพตช์ 0003 ซีดเดียวกันจะให้เสียงที่เหมือนกันทุกไบต์ในทุกครั้งที่รัน

ไฟล์เสียงต้นแบบดิบเป็นตัวอย่างของเสียงที่เกิดขึ้นครั้งเดียว การอ่านครั้งต่อ ๆ ไปจะไม่ออกมาเหมือนกันเป๊ะ สิ่งที่คุณได้ยินใน
การอ่านทุกครั้งหลังจากนั้นคือขั้นตอนที่ 2: ใช้ไฟล์เสียงต้นแบบเป็นเสียงอ้างอิง บวกกับซีดของตัวเลือกนั้นเอง นี่คือเหตุผลที่เว็บ UI
ทำขั้นตอนที่ 2 ทันทีหลังออกแบบเสร็จ และแสดงทั้งสองเสียงบนการ์ดตัวเลือก

เอนจินคือ audio.cpp v0.7.2 พร้อมแพตช์ของเรา (`patches/`) ส่วนโมเดลคือ VoxCPM2 Q8_0 GGUF ใช้ VRAM สูงสุด ≈ 2.8 GB
และใช้เวลาประมวลผลประมาณ 2 วินาทีต่อเสียงพูด 1 วินาทีบน GTX 1050 Ti รายละเอียดและผลการวัด: [docs/4gb.md](docs/4gb.md)

## ติดตั้งอย่างรวดเร็ว ไม่ต้องใช้คอมไพเลอร์ (Windows 10/11, NVIDIA GPU ≥ 4 GB)

สิ่งที่ต้องมี: ไดรเวอร์ NVIDIA ≥ 570 และ Python 3.10-3.13 แบบ 64 บิต (`winget install Python.Python.3.12`) แค่นั้นพอ
ไม่ต้องมี Visual Studio ไม่ต้องใช้ตัวติดตั้ง CUDA ไม่แน่ใจว่าใช้การ์ดจออะไร? รัน `nvidia-smi` ใน PowerShell แล้วจะเห็นชื่อ GPU
เวอร์ชันไดรเวอร์ และหน่วยความจำ ไม่มีการ์ด NVIDIA? ดู "AMD / Intel" ด้านล่าง

เมื่อใช้ [Git](https://git-scm.com/download/win):

```powershell
git clone https://github.com/alexturkey/voxcpm2-turkce-ses-tasarimi.git
cd voxcpm2-turkce-ses-tasarimi
powershell -NoProfile -ExecutionPolicy Bypass -File scripts\kur.ps1 -Kok C:\vox
```

เมื่อไม่ใช้ Git: ในหน้านี้คลิก **Code → Download ZIP** แตกไฟล์ เปิดโฟลเดอร์ที่แตกออกมา
`voxcpm2-turkce-ses-tasarimi-main` พิมพ์ `powershell` ในแถบที่อยู่ของ File Explorer แล้วกด Enter จากนั้นรัน
บรรทัดสุดท้ายด้านบน Git จำเป็นเฉพาะเมื่อสร้างจากซอร์สเท่านั้น

`-ExecutionPolicy Bypass` มีผลกับโปรเซสนี้โปรเซสเดียวและไม่เปลี่ยนการตั้งค่าระบบใด ๆ เช่นเดียวกับสคริปต์ติดตั้งทุกตัว ควรอ่าน `scripts\kur.ps1`
ก่อนรัน คำสั่งเดียว ~10 นาที ดาวน์โหลด ~3.7 GB ทุกไฟล์ตรวจสอบด้วย sha256: โมเดล (2.95 GB), DLL รันไทม์ CUDA 12.8 ในรูป
zip แบบพกพา (ไม่ติดตั้งลงระบบ ไม่แตะ PATH), **เอนจินที่สร้างไว้แล้ว** จากหน้า Releases, `.venv` ที่มีแพ็กเกจ
Python สองตัว, `ayarlar.json` และการตรวจ GPU ขั้นสุดท้าย (`KONTROL_OK`) ถ้าล้มเหลวตรงไหนให้รันใหม่ ไฟล์ที่ตรวจสอบแล้วจะถูก
ข้ามไป จากนั้นเริ่มเว็บ UI: ดับเบิลคลิก **`baslat.bat`** ในโฟลเดอร์รีโพ มันจะเริ่มหน้าจอและเปิด
**http://127.0.0.1:8765/** ในเบราว์เซอร์เมื่อพร้อม ปิดหน้าต่างสีดำ (หรือกด Ctrl+C ในหน้าต่างนั้น) เพื่อหยุด
ทำแบบเดียวกันจาก PowerShell:

```powershell
.venv\Scripts\python.exe -m ses_tasarim.arayuz
```
จากนั้นเปิด **http://127.0.0.1:8765/** เอง (เมื่อเริ่มด้วยวิธีนี้ หน้าจอจะไม่เปิดเบราว์เซอร์ให้ และรับการเชื่อมต่อจาก
localhost เท่านั้น)

> **`audiocpp_cli.exe` ใน zip ของรีลีสไม่ได้มีไว้ให้ดับเบิลคลิก** มันเป็นเอนจินแบบบรรทัดคำสั่งที่
> ต้องมี DLL ของ CUDA และโมเดลวางอยู่ข้าง ๆ `kur.ps1` จะจัดวางทุกอย่างให้ และแพ็กเกจ Python จะเป็นตัวสั่งงานมัน
> ถ้าดับเบิลคลิกจะเห็นแค่ "cudart64_12.dll not found"

**GPU ที่รองรับ (รีลีส v0.3.2):** มีโค้ดเนทีฟสำหรับ GTX 10xx (sm_61), RTX 20xx (sm_75), RTX 30xx (sm_86), RTX 40xx
(sm_89) และ RTX 50xx (sm_120a) ส่วน GPU CUDA อื่น ๆ ตั้งแต่ Pascal ขึ้นไปจะรัน PTX ที่ฝังไว้ผ่านไดรเวอร์ (เริ่มครั้งแรก
ช้ากว่า) Maxwell (GTX 9xx) และรุ่นเก่ากว่าไม่รองรับใน CUDA 12.8 เราทดสอบบน GTX 1050 Ti 4 GB (รวมถึงผ่าน Docker Desktop/WSL2 บน Windows เฉพาะ CLI) และวัดผลโดย @mslmyilmaz5 (#15): RTX 3060 Ti 8 GB, Ubuntu 24.04 Docker,
CUDA 12.8.1 (รายละเอียดใน [docs/linux.md](docs/linux.md)) ยินดีรับรายงานจากการ์ดรุ่นอื่นใน [Discussions](https://github.com/alexturkey/voxcpm2-turkce-ses-tasarimi/discussions)

**AMD / Intel (ทดลอง):** เอนจิน Vulkan แยกต่างหาก (ไม่ต้องใช้ CUDA) ติดตั้งด้วย `scripts\kur.ps1 -Kok C:\vox -Vulkan` เราทดสอบบนการ์ด NVIDIA ของเราผ่านแบ็กเอนด์ Vulkan (ที่นั่นช้ากว่า CUDA ได้เสียงเดิมเมื่อใช้ seed เดิม ยังไม่มีการเทียบความเร็วแบบสะอาด) และบนกราฟิกในตัว Intel HD Graphics 630 (ใช้การคำนวณราว 35-50 วินาทีต่อเสียงพูด 1 วินาที) แต่บน AMD เรา**ยังไม่ได้**ทดสอบเอง หากคุณลอง โปรดโพสต์ผลใน Discussions หากมีอุปกรณ์ Vulkan มากกว่าหนึ่งตัว (ในตัว + แยก) ตัวติดตั้งจะเขียนหมายเลขของการ์ดแยกเป็น `cihaz` ลงใน `ayarlar.json`

**การทดสอบจากชุมชน (AMD):** @mitraTR รัน v0.1.1 ด้วย Vulkan บน AMD Radeon RX 6900 XT ใน Windows 11: การติดตั้ง การออกแบบเสียง การอ่าน เว็บอินเทอร์เฟซ และชุดทดสอบทำงานได้ทั้งหมด การอ่านใช้เวลาประมวลผลราว 0.8-0.9 วินาทีต่อเสียงพูด 1 วินาที ([รายงานใน #6](https://github.com/alexturkey/voxcpm2-turkce-ses-tasarimi/issues/6#issuecomment-6581393655)) ให้ติดตั้งในโฟลเดอร์สั้น ๆ ที่พาธมีแต่อักขระ ASCII (เช่น `C:\vox`) เพราะบน Windows เอนจินเปิดพาธที่มีอักษรไทยหรืออักขระนอก ASCII อื่นไม่ได้ รายงานทั้งหมดจนถึงตอนนี้: [ฮาร์ดแวร์ที่ทดสอบแล้ว](docs/donanim_testleri.md)

**หมายเหตุเรื่อง Vulkan:** ตั้งแต่เอนจิน v0.3.1 เวลาของแต่ละคำใช้งานบน Vulkan ได้แล้ว มีสองแพ็กเกจ: `vulkan` ต้องใช้ CPU ที่มี AVX2 (Intel Core ส่วนใหญ่ตั้งแต่ปี 2013, AMD ตั้งแต่ปี 2015; Pentium/Celeron หลายรุ่นไม่มี) ส่วน [`vulkan-uyumlu`](https://github.com/alexturkey/voxcpm2-turkce-ses-tasarimi/releases/download/v0.3.2/voxcpm2-turkce-ses-tasarimi-motor-v0.3.2-win64-vulkan-uyumlu.zip) ทำงานได้กับ CPU x86 64 บิตทุกตัว แต่การอ่านครั้งแรกของเสียงหนึ่งจะใช้เวลาราว 2.2 เท่า (การอ่านครั้งต่อไปเร็วเท่าเดิม) `kur.ps1 -Vulkan` ตรวจ CPU และเลือกแพ็กเกจเอง บนกราฟิกในตัว เอนจินใช้ RAM ราว 8 GB ขณะอ่าน การเปิดครั้งแรกบน Vulkan อาจใช้เวลาสองสามนาทีเพราะต้องคอมไพล์เชเดอร์ของ GPU การอ่านครั้งต่อไปจะเร็วขึ้น รายละเอียด: [docs/vulkan.md](docs/vulkan.md)

## การใช้งาน

บรรทัดคำสั่ง:
```powershell
# list voices
.venv\Scripts\python.exe -m ses_tasarim.oku --liste
# read with a bundled voice (one sentence per line; blank line or "|| paragraf" = longer pause, "|| 0,8" = 0.8 s)
.venv\Scripts\python.exe -m ses_tasarim.oku --ses hazir/belgesel_hanim --metin @metin.txt --cikti cikti\deneme
# design a new voice: 3 variants, 3 seeds
.venv\Scripts\python.exe -m ses_tasarim.tasarla --ad deniz_feneri --cesit 3 --tarif "A calm Turkish woman ..." --metin @tanitim.txt
# read with variant 2 of it
.venv\Scripts\python.exe -m ses_tasarim.oku --ses deniz_feneri/2 --metin @metin.txt --cikti cikti\deniz
# design, then read a text with each variant's lasting voice (dinleme.wav in each variant folder)
.venv\Scripts\python.exe -m ses_tasarim.tasarla --ad deniz_feneri --cesit 3 --tarif "A calm Turkish woman ..." --metin @tanitim.txt --dinleme @metin.txt
```
กฎของข้อความ: เขียนตัวเลขเป็นคำ ไม่ใช้เครื่องหมายคำพูด (เครื่องมือจะปฏิเสธตัวเลขและเครื่องหมายคำพูด) หนึ่งประโยคต่อบรรทัด
บรรทัดละ ≤ 2000 ตัวอักษร การเว้นจังหวะหลังบรรทัด: `|| bagli` 0.25 วินาที, `|| normal` 0.5 วินาที, `|| paragraf` 1 วินาที, `|| agir` 1.5 วินาที
หรือกำหนดความยาวเอง `|| 0,8` (0-5 วินาที ตัวเลขในเครื่องหมายนี้ใช้ได้) `ayarlar/okunus_sozlugu.tsv` ใช้แก้การออกเสียงคำต่างประเทศในข้อความภาษาตุรกี
ภาษาจะถูกตรวจจับจากข้อความ (ตัวอักษรภาษาตุรกี ระบบตัวเขียน คำที่พบบ่อย ถ้าไม่แน่ใจจะใช้ `dil` ในการ์ดเสียง ส่วน `--dil <code>` ใส่หรือไม่ก็ได้) สำหรับข้อความที่ไม่ใช่ภาษาตุรกี ใช้อะพอสทรอฟีได้ ไม่ใช้พจนานุกรมภาษาตุรกี
แต่ตัวเลขยังคงถูกปฏิเสธ ถ้าระหว่างอ่านมีข้อความ `speed gate: satır [...]` ขึ้นมา ให้ฟังบรรทัดเหล่านั้น

### เว็บ UI

ใช้ได้เฉพาะในเครื่อง (127.0.0.1): `.venv\Scripts\python.exe -m ses_tasarim.arayuz` → เปิด http://127.0.0.1:8765/ เอง
(พอร์ตอื่น: `--port 8800`) หรือดับเบิลคลิก `baslat.bat` หยุดเซิร์ฟเวอร์ด้วย Ctrl+C มีสามแท็บ: *ออกแบบเสียง*
*อ่านด้วยเสียงนี้* และ *โคลนเสียง* ลำดับการใช้งานปกติ: *ออกแบบ* → ฟังตัวเลือกต่าง ๆ → *เพิ่มในรายการอ่านของฉัน* →
*อ่านด้วยเสียงนี้* → ดาวน์โหลด หรือเลือกเสียงสำเร็จรูปจากเมนูเสียงแล้วอ่านได้เลย

- **เวอร์ชันที่ส่วนหัว** ตัวอักษรเล็กและจาง `v0.3.1 · <short commit>` (มี `+` เมื่อไฟล์ที่ติดตามอยู่มีการเปลี่ยนแปลงที่ยังไม่ commit
  และแสดงแค่เวอร์ชันเมื่อไม่มี git) ภาพหน้าจอและวิดีโอจึงบอกได้ว่าใช้เวอร์ชันไหน
- **สองเสียงบนการ์ดตัวเลือกทุกใบ** ด้านบนสีเทาคือ *เสียงต้นแบบดิบ*: สร้างขึ้นครั้งเดียวและจะไม่ออกมา
  เหมือนเดิมอีก ด้านล่างในกรอบสีส้มคือ *↻ นี่คือเสียงที่คุณจะได้ยินตลอด*: ไฟล์เสียงต้นแบบถูกนำมาใช้เป็นเสียงอ้างอิงแล้วอ่าน
  อีกครั้งด้วยซีดของตัวเลือกนั้นเอง (แสดงไว้บนการ์ด) นี่คือเสียงที่จะได้ยินในการอ่านทุกครั้งหลังจากนี้
  ด้านล่างมี *อ่านด้วยเสียงนี้* และ *เพิ่มในรายการอ่านของฉัน* กด *ออกแบบ* ครั้งเดียวทำได้ทั้งสองอย่าง: ออกแบบทุก
  ตัวเลือก แล้วอ่านข้อความของคุณด้วยเสียงคงที่ของแต่ละตัวเลือก แถบความคืบหน้าแถบเดียวนับทั้งสองช่วง โฟลเดอร์ตัวเลือก
  จะได้ไฟล์ `dinleme.wav` ถ้าการอ่านนั้นหยุดกลางคัน งานออกแบบจะยังอยู่ และการ์ดจะแสดงหมายเหตุ
- **หน้าต่าง "ข้อความที่อยากฟัง"** ในแท็บ *ออกแบบเสียง* ช่อง *↻ ข้อความที่อยากฟัง* เก็บข้อความที่เสียงคงที่แต่ละเสียง
  จะอ่าน (ถ้าเว้นว่างจะอ่านประโยคตัวอย่าง) คลิกที่ช่องนี้เพื่อเปิดสมุดอ่านในหน้าต่าง: เลขบรรทัด
  เมนูบรรทัด และแถบเว้นจังหวะ *ตกลง* จะเขียนข้อความและการเว้นจังหวะกลับลงช่อง *ยกเลิก* หรือ Esc จะไม่เปลี่ยนอะไร
  แท็บอ่านเก็บข้อความของตัวเองแยกไว้
- **สมุดอ่าน** หนึ่งประโยคต่อบรรทัด คลิกเลขบรรทัดเพื่อเปิดเมนูบรรทัด (ย้ายขึ้นหรือลง ย้ายไปตำแหน่งที่ต้องการ
  ทำสำเนา ลบ; Alt+↑/↓, Alt+Shift+↓ หรือลากที่เลขบรรทัด; Ctrl+Z ย้อนทั้งข้อความและการเว้นจังหวะพร้อมกัน)
  คลิกแถบบาง ๆ ระหว่างสองบรรทัดเพื่อเลือกการเว้นจังหวะ (bagli 0.25 · normal 0.5 · paragraf 1 · agir 1.5 วินาที หรือกำหนด
  เอง 0-5 วินาทีด้วยรูปเฟือง) กด Enter สองครั้งเพื่อขึ้นย่อหน้า (1 วินาที) และบรรทัดว่างจะกลายเป็นแถบเว้นจังหวะ ขณะเล่นผลลัพธ์
  บรรทัดที่กำลังอ่านจะเรืองแสงและเลื่อนมาให้เห็น *▶ ฟังจากตรงนี้* ในเมนูบรรทัดจะเล่นตั้งแต่บรรทัดนั้น
  ข้อความและการเว้นจังหวะยังอยู่แม้โหลดหน้าใหม่ (ที่เก็บข้อมูลของเบราว์เซอร์)
- **ฉบับร่าง** ปุ่ม *📄 ฉบับร่าง* อยู่ในสมุดทั้งสองเล่ม (แท็บอ่านและหน้าต่าง) บันทึกข้อความปัจจุบันพร้อม
  การเว้นจังหวะเป็นฉบับร่าง โหลดด้วยการคลิกครั้งเดียว (Ctrl+Z ย้อนได้) และใช้ ⋯ เพื่อเขียนทับ เปลี่ยนชื่อ หรือลบ ฉบับร่าง
  เก็บไว้ใน `sesler/taslaklar.json` และจะไม่เข้าไปอยู่ในรีโพเลย
- **รายการอ่านและเมนูเสียง** บนการ์ดตัวเลือก *เพิ่มในรายการอ่านของฉัน* จะเปิดช่องใส่ชื่อ: ตั้งชื่อ
  ของตัวเองให้ตัวเลือกนั้นแล้วกด ✓ เพื่อเพิ่ม *ชื่อการสร้าง* จะยังคงอยู่บนทุกตัวเลือกของการสร้างรอบนั้น ในแท็บ *อ่านด้วยเสียงนี้* ปุ่ม
  เสียง (ธง + ชื่อ) จะเปิดเมนูเสียง: *รายการอ่านของฉัน* อยู่บนสุด ตามด้วยเสียงสำเร็จรูปพร้อมธง (ภาษาของหน้าจอ
  มาก่อน) แต่ละแถวมี ▶ ฟัง (เสียงคงที่ถ้ามี) รูปหัวใจ (เพิ่มหรือเอาออก) และ ⋯ ใช้ ↑/↓ และ
  Enter เพื่อเลือก Esc เพื่อปิด และระบบจะจำเสียงล่าสุดไว้ รายการเก็บอยู่ใน `sesler/okuma_listesi.json` นอก
  รีโพ และยังอยู่แม้รีสตาร์ต
- **การจัดการเสียง** เมนู ⋯ (แถวในเมนูเสียงหรือการ์ดตัวเลือก) มี *อ่านด้วยเสียงนี้* เพิ่มเข้าหรือเอาออกจาก
  รายการ *เปลี่ยนชื่อ* (ปล่อยชื่อว่างเพื่อกลับไปใช้ชื่อเดิม; *กลับไปใช้ชื่อเดิม*) *ลบ* สำหรับเสียงที่ออกแบบเอง และ *ซ่อน*
  สำหรับเสียงสำเร็จรูป ทั้งสองอย่างจะถามก่อน เสียงที่ลบจะย้ายไปที่ `sesler/_cop/` ส่วนการซ่อนไม่แตะไฟล์ในรีโพเลย
  *เสียงที่ซ่อนและลบแล้ว (N)* ที่ด้านล่างของเมนูเสียงมี *กู้คืน* ชื่อที่ตั้งเองและเสียงที่ซ่อนเก็บไว้
  ใน `sesler/yerel_katman.json` เสียงที่เปลี่ยนชื่อแล้วจะแสดงที่มาเป็นสีเทา (*ชื่อการสร้าง · ตัวเลือก N*) ส่วน
  ⋯ → *ไปที่การสร้าง* จะเปิดงานออกแบบของมัน
- **ปุ่มลัดและไฟล์** Ctrl+Enter (⌘+Enter บน Mac) จะเริ่ม *ออกแบบ* หรือ *อ่านด้วยเสียงนี้* ในแท็บที่เปิดอยู่
  แถบความคืบหน้าแสดง *เวลาที่ผ่านไป / ~เวลาทั้งหมด* โดยประมาณการจากงานก่อน ๆ บนเครื่องของคุณ ไฟล์ที่ดาวน์โหลดจะตั้งชื่อ
  ตามชื่อเสียงและเวลา (`Voice_Name_2026-11-02_0152.wav`)

**โคลนเสียง (เสียงของคุณเองหรือเสียงที่ได้รับความยินยอม)** ในแท็บ *โคลนเสียง* ของหน้าจอ ให้ใส่ไฟล์บันทึกเสียงของคุณ (wav/mp3/flac/ogg แนะนำเสียงพูดที่ชัดเจน 5-30 วินาที ถ้าสั้นกว่า 3 วินาทีจะถูกปฏิเสธ ถ้ายาวเกิน 36 วินาทีจะถูกตัด) ข้อความถอดเสียงที่ตรงกันทุกคำ และข้อความที่จะอ่าน ปุ่มจะกดไม่ได้จนกว่าคุณจะติ๊ก "เสียงนี้เป็นของฉัน หรือฉันได้รับอนุญาตอย่างชัดแจ้งจากเจ้าของเสียงแล้ว" ไฟล์บันทึกเสียงจะถูกส่งไปที่เซิร์ฟเวอร์ในเครื่อง (127.0.0.1) เท่านั้น ประมวลผลในโฟลเดอร์ชั่วคราวพร้อมกับการเข้ารหัสเสียงอ้างอิง และโฟลเดอร์นั้นจะถูกลบเมื่องานจบ แม้งานจะล้มเหลวก็ตาม ไม่มีอะไรถูกส่งผ่านเครือข่าย เก็บไว้เฉพาะผลลัพธ์สังเคราะห์ (หน้าจอ: `sesler/_okumalar/<job>/`, CLI: `--cikti`) ผลลัพธ์คือ `klon_synthetic.wav` ที่มีแท็ก "synthetic" เมื่อแชร์ให้ระบุว่าสร้างโดย AI CLI: `python -m ses_tasarim.klonla --kayit myvoice.wav --kayit-metni @transcript.txt --metin "Hello." --cikti out/clone --onay`

## คำถามที่พบบ่อย

**โมเดลหรือเอนจิน? อะไรคืออะไร?** VoxCPM2 (OpenBMB) คือ*โมเดล*: โครงข่ายประสาทขนาด 2 พันล้านพารามิเตอร์ที่แปลงข้อความ
เป็นเสียงพูด ส่วน audio.cpp คือ*เอนจิน*: โปรแกรม C++/CUDA ที่รันโมเดลบน GPU ของคุณ (`audiocpp_cli.exe`) แพตช์
ของเราแก้ที่เอนจิน ไม่ได้แก้โมเดล: ทำให้ VoxCPM2 ใส่ลงใน 4 GB ได้ และทำให้ซีดเดียวกันให้เสียงเดียวกัน
ทุกครั้ง แพ็กเกจ Python ในรีโพนี้ทำแค่เตรียมข้อความ เรียกเอนจิน และรวบรวมไฟล์

**ใช้ GPU อะไรได้บ้าง?** ดู "GPU ที่รองรับ" ด้านบน: NVIDIA ตั้งแต่ GTX 10xx ขึ้นไป VRAM 4 GB ขึ้นไป ไดรเวอร์ ≥ 570 ในรีลีสมีโค้ดเนทีฟ
สำหรับ sm_61/75/86/89/120a ส่วนการ์ดอื่นตั้งแต่ Pascal ขึ้นไปจะใช้ PTX ที่ฝังไว้ (เริ่มครั้งแรกช้ากว่า) AMD/Intel: zip Vulkan แบบทดลอง `kur.ps1 -Vulkan` เราทดสอบเองแล้วบนกราฟิกในตัว Intel HD Graphics 630 ส่วน @mitraTR รันรุ่นก่อนหน้า v0.1.1 บน AMD RX 6900 XT แพ็กเกจ v0.3.1 ใหม่ยังไม่มีใครลองบน AMD (ดู "AMD / Intel" ด้านบน) แบบใช้ CPU อย่างเดียว (`"backend": "cpu"` ใน `ayarlar.json`) รันได้แต่
ช้ากว่า GTX 1050 Ti ราว 6 เท่า (วัดที่เอนจิน 535 วินาที เทียบกับ 94 วินาที สำหรับเสียงพูด 48 วินาที) และไม่ใช่วิธีที่รองรับ

**เร็วแค่ไหน?** วัดบน GTX 1050 Ti 4 GB (i7-7700HQ): ออกแบบหนึ่งตัวเลือก (ไฟล์เสียง ≈ 25 วินาที) ใช้ 55 วินาที การอ่านใช้เวลาประมวลผล ≈ 2 วินาที
ต่อเสียงพูด 1 วินาที (real-time factor 1.9-2.8) หลังจากเข้ารหัสเสียงอ้างอิงครั้งเดียว ~50 วินาทีต่อเสียง (แคชไว้บน
ดิสก์) และโหลดโมเดล 10-20 วินาทีต่อชุดงาน ใช้ VRAM สูงสุด 2.6-2.9 GB การ์ดรุ่นใหม่จะเร็วกว่านี้ ตัวเลขและวิธีวัด:
[docs/4gb.md](docs/4gb.md)

**โคลนเสียงได้ไหม?** โมเดล VoxCPM2 ที่อยู่เบื้องหลังเลียนแบบเสียงจากไฟล์เสียงอ้างอิงได้ และส่วนโคลน
เสียงก็ใช้ความสามารถนี้ ใช้ได้เฉพาะกับเสียงของคุณเอง หรือเมื่อได้รับอนุญาตอย่างชัดแจ้งจากเจ้าของเสียงเท่านั้น
และหน้าจอจะขอให้คุณยืนยันการอนุญาตนั้น การออกแบบเสียงไม่ต้องใช้ไฟล์บันทึกเสียง: เริ่มจากคำอธิบายเป็นข้อความภาษาอังกฤษหรือจีน และ
"เสียงอ้างอิง" ที่ใช้อ่านด้วยเสียงที่ออกแบบไว้คือไฟล์เสียงต้นแบบที่โมเดลสังเคราะห์ขึ้นเอง ห้ามใช้เพื่อแอบอ้างเป็นผู้อื่น ฉ้อโกง
หรือหลอกลวง ดู [ETHICS.md](ETHICS.md) ระบุว่าสิ่งที่คุณเผยแพร่สร้างโดย AI

**เขียนคำอธิบายเสียงให้ดีได้อย่างไร?** เขียนเป็นภาษาอังกฤษ 1-3 ประโยค: อายุและเพศ โทนเสียง (ทุ้ม/ใส อบอุ่น
ขึ้นจมูก แหบ) น้ำเสียงและบทบาท (ผู้บรรยายสารคดีที่สุขุม พิธีกรที่กระตือรือร้น) จังหวะ (ช้า หนักแน่นเป็นจังหวะ) และ
"clean studio recording, no background noise" ให้เป็นคำอธิบาย ไม่ใช่บทพูด และไม่ใช้วงเล็บ ขอ 3-5
ตัวเลือกแล้วฟัง: ซีดเปลี่ยนเสียงได้มาก ข้อความที่อ่านตอนสร้างเสียงให้ใช้ประโยคธรรมชาติ 1-3 ประโยคในภาษาของเสียงนั้น ใน
อารมณ์ที่คุณต้องการ (เสียงพูดยาวไม่เกิน ~30 วินาที) เวลาอ่านให้ใช้หนึ่งประโยคต่อบรรทัด แบ่งประโยคยาว และเขียนตัวเลขเป็นคำ
