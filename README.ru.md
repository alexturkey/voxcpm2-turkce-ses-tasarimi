# voxcpm2-turkce-ses-tasarimi

**Дизайн турецких голосов с VoxCPM2 на видеокарте с 4 ГБ.** Опишите голос по-английски, дайте модели его создать, выберите
понравившийся вариант и читайте этим голосом любой турецкий текст. В комплекте: установщик в одну команду, движок
[audio.cpp](https://github.com/0xShug0/audio.cpp) с нашим патчем, который помещается в GTX 1050 Ti (4 ГБ), небольшой локальный
веб-интерфейс и четырнадцать готовых синтетических голосов: семь турецких и семь дикторов-носителей английского, французского,
немецкого, испанского, русского, китайского и японского языков.

- Приложение читает на 30 языках; интерфейс тоже переведён на 30 языков.
- 14 готовых голосов: 7 турецких и по одному на английском, французском, немецком, испанском, русском, китайском и японском.
- Веб-интерфейс (v0.2.0): на каждой карточке варианта два голоса, черновой голос дизайна и голос, который вы будете слышать
  всегда; список чтения с меню голосов; переименование, скрытие и удаление голосов; черновики для читаемых текстов. См. «Веб-интерфейс» в разделе «Использование».

[Как это помещается в 4 ГБ](docs/4gb.md) · [Ubuntu / Linux](docs/linux.md) · [macOS](docs/mac.md) · [Инструкция по установке для ИИ-агентов](AGENTS.md) · [Ответственное использование](ETHICS.md)

> Голоса в комплекте синтетические, они созданы по текстовому описанию. Раздел клонирования голоса предназначен только для
> вашего собственного голоса или голоса, используемого с явного разрешения его владельца; интерфейс просит подтвердить это
> разрешение. Выдача себя за другого, мошенничество и обман запрещены. Помечайте созданное как сгенерированное ИИ. См. [ETHICS.md](ETHICS.md).

## 30 языков

Мы сделали один документальный ролик о Каппадокии на 8 языках: турецком, английском, французском, немецком, испанском,
русском, китайском и японском. У каждого языка свой **диктор-носитель**, созданный в VoxCPM2 по описанию на английском. Всё
сгенерировано полностью локально на GTX 1050 Ti с 4 ГБ, с одинаковым фиксированным качеством (16 шагов, cfg 2.0). Семь
дикторов входят в комплект вместе с их промптом, текстом дизайна, сидом и референсной записью.

```powershell
.venv\Scripts\python.exe -m ses_tasarim.tasarla --ad narrator_es --dil es --cesit 3 --tarif "A deep-voiced Spanish man ..." --metin @texto.txt
```

**Почему по одному предложению.** VoxCPM2 нестабилен при одной длинной генерации (примерно дольше 30 секунд): темп
ускоряется, а голос может «уплыть». Здесь голос держится на фиксированной референсной записи и сиде, а длинный текст
читается по одному предложению на строку, поэтому тембр и манера остаются одинаковыми от первого предложения до последнего.
Для других языков, кроме турецкого, турецкий словарь произношения не применяется. Все 30 языков, которые поддерживает VoxCPM2, проверены и работают; для языков без
готового голоса используйте `--dil <code>`. Команды для каждого языка и уроки, которые мы извлекли:
[docs/cok_dilli.md](docs/cok_dilli.md). Навык Claude Code для всего процесса дизайна:
[.claude/skills/ses-tasarimi/SKILL.md](.claude/skills/ses-tasarimi/SKILL.md).

**144 примера промптов для старта.** 18 ролей (диктор документального фильма, ведущий новостей, рекламный голос, аудиокнига,
бабушка-сказочница, ведущий подкаста, учитель, трейлер фильма, гид по медитации, спортивный комментатор и другие, мужские и
женские) на каждом из 8 языков. Промпт написан по-английски и указывает национальность и родной акцент говорящего; к нему
прилагается текст, который читается при создании голоса, на этом языке и под роль. Выберите один, прослушайте
варианты, оставьте понравившийся: `python -m ses_tasarim.tasarla --ornek fr_sesli_kitap_kadin --cesit 3` или выберите
*Пример описания* в веб-интерфейсе. Полный список: [docs/ornek_tarifler.md](docs/ornek_tarifler.md).

**Озвучивайте свои видео собственным голосом.** [DubWorld](https://github.com/alexturkey/dubworld) это наша локальная программа
для дубляжа видео; она устанавливает этот репозиторий как свой голосовой движок VoxCPM2. Голос, созданный здесь, используется там через
`ses.voxcpm2_ses = "<name>/<variant>"`.

## Быстрый старт (Windows, 3 шага)

1. **Скачайте** код: [voxcpm2-turkce-ses-tasarimi-main.zip](https://github.com/alexturkey/voxcpm2-turkce-ses-tasarimi/archive/refs/heads/main.zip).
   Готовый пакет движка для вашей видеокарты установщик загрузит сам на шаге 3:
   NVIDIA → [пакет CUDA](https://github.com/alexturkey/voxcpm2-turkce-ses-tasarimi/releases/download/v0.1.1/voxcpm2-turkce-ses-tasarimi-motor-v0.1.1-win64-cuda12.8.zip),
   AMD / Intel → [пакет Vulkan, экспериментальный](https://github.com/alexturkey/voxcpm2-turkce-ses-tasarimi/releases/download/v0.1.1/voxcpm2-turkce-ses-tasarimi-motor-v0.1.1-win64-vulkan.zip)
   (уже скачали? добавьте `-HazirZip <path to the zip>` к команде ниже).
2. **Распакуйте** zip, откройте папку `voxcpm2-turkce-ses-tasarimi-main`, введите `powershell` в адресной строке Проводника
   и нажмите Enter.
3. **Запустите** установщик (нужен 64-битный Python 3.10-3.13; для CUDA драйвер NVIDIA ≥ 570), затем дважды щёлкните **`baslat.bat`**:
   ```powershell
   powershell -NoProfile -ExecutionPolicy Bypass -File scripts\kur.ps1 -Kok C:\vox
   ```
   AMD / Intel: добавьте в конце `-Vulkan`. Интерфейс откроется по адресу http://127.0.0.1:8765/.

Zip движка не является самостоятельным приложением (его exe нужны модель и DLL, которые настраивает установщик). Подробности,
список видеокарт и частые проблемы: «Быстрая установка» ниже.

## Ubuntu / Linux (NVIDIA CUDA, экспериментально)

Соберите движок с патчем командой `bash scripts/kur-linux.sh` или используйте `Dockerfile.linux`, чтобы собрать и запустить его в
окружении Ubuntu 24.04 / CUDA 12.8.1. Нужны видеокарта NVIDIA и совместимый драйвер; нативному установщику также нужны CUDA

Требования, команды, выбор архитектуры и объём проверки: [docs/linux.md](docs/linux.md).

Нужны Xcode Command Line Tools (`xcode-select --install`) и [Homebrew](https://brew.sh):

```bash
brew install cmake python@3.12
git clone https://github.com/alexturkey/voxcpm2-turkce-ses-tasarimi.git
```

Установщик скачивает модель, собирает движок с патчем под Metal (~1 мин) и настраивает всё в `~/vox`.

побайтово одинаковый звук, пик ~5,3 ГБ RAM, без замедления от нагрева за 12 мин непрерывного чтения. Подробности и
замеры: [docs/mac.md](docs/mac.md).

**Нативное приложение для Mac (без Python, Homebrew и Терминала):** [macos/README.md](macos/README.md). В него входит тот же
движок с патчем, а модель скачивается при первом запуске; пока его собирают из исходников в Xcode.

## Как это работает

1. **Дизайн голоса.** *Описание голоса* на английском + *текст, который читается при создании голоса* (на языке голоса) + число
   вариантов. Каждый вариант получает свой сид; движок принимает `(description)text` и возвращает по одной записи дизайна
   на каждый сид. Текст нужен как короткий образец, чтобы познакомиться с голосом: 1-2 предложения, не больше ~20 с (интерфейс
   показывает оценку и не запускается, если выходит больше 22 с); длинный текст относится к шагу 2.
2. **Чтение по референсу.** Запись дизайна подаётся на **оба** входа движка (`audio` и `voice_ref`) вместе с её
   расшифровкой (`reference_text`) и новым текстом для чтения, с тем же сидом. Голос задаётся записью, а не описанием,
   поэтому он не «уплывает» от текста к тексту. Текст читается по предложениям.
3. Качество фиксировано: 16 шагов диффузии, CFG 2.0. Сид не является настройкой качества.

Черновая запись дизайна это однократный образец голоса; ни одно последующее чтение не звучит в точности так же. В каждом
последующем чтении вы слышите шаг 2: запись дизайна как референс плюс собственный сид варианта. Поэтому веб-интерфейс
выполняет шаг 2 сразу после дизайна и показывает оба голоса на карточке варианта.

Движок: audio.cpp v0.7.2 с нашим патчем (`patches/`), модель: VoxCPM2 Q8_0 GGUF. Пиковое потребление VRAM ≈ 2,8 ГБ;
около 2 с вычислений на 1 с речи на GTX 1050 Ti. Подробности и замеры: [docs/4gb.md](docs/4gb.md).

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File scripts\kur.ps1 -Kok C:\vox
```

Без Git: на этой странице нажмите **Code → Download ZIP**, распакуйте архив, откройте распакованную папку
`voxcpm2-turkce-ses-tasarimi-main`, введите `powershell` в адресной строке Проводника и нажмите Enter, затем выполните
последнюю строку выше. Git нужен только для сборки из исходников.

`-ExecutionPolicy Bypass` действует только на этот процесс и не меняет системных настроек; как и с любым скриптом установки,
прочитайте `scripts\kur.ps1` перед запуском. Одна команда, ~10 мин, ~3,7 ГБ загрузки, всё проверяется по sha256: модель (2,95 ГБ), runtime-DLL CUDA 12.8 в виде
портативных zip (без установки в систему, PATH не трогается), **готовый движок** со страницы Releases, `.venv` с двумя
пакетами Python, `ayarlar.json` и финальная проверка видеокарты (`KONTROL_OK`). После любого сбоя просто запустите заново;
уже проверенные файлы пропускаются. Затем запустите веб-интерфейс: дважды щёлкните **`baslat.bat`** в папке репозитория. Он
запускает интерфейс и, когда тот готов, открывает **http://127.0.0.1:8765/** в браузере; чтобы остановить, закройте чёрное окно (или нажмите в нём Ctrl+C).
То же самое из PowerShell:

```powershell
.venv\Scripts\python.exe -m ses_tasarim.arayuz
```
затем откройте **http://127.0.0.1:8765/** сами (при таком запуске интерфейс не открывает браузер; он слушает только
localhost).

> **`audiocpp_cli.exe` из zip релиза не предназначен для запуска двойным щелчком.** Это движок командной строки, которому
> нужны DLL CUDA и модель рядом; `kur.ps1` раскладывает всё по местам, а управляет им пакет Python.
> Двойной щелчок лишь покажет «cudart64_12.dll not found».

**Поддерживаемые видеокарты (релиз v0.1.1):** нативный код для GTX 10xx (sm_61), RTX 20xx (sm_75), RTX 30xx (sm_86), RTX 40xx
(sm_89) и RTX 50xx (sm_120a); любая другая CUDA-видеокарта начиная с Pascal выполняет встроенный PTX через драйвер (первый
запуск медленнее). Maxwell (GTX 9xx) и более старые не поддерживаются CUDA 12.8. Мы тестировали на GTX 1050 Ti 4 ГБ (также через Docker Desktop/WSL2 в Windows, только CLI); замеры от @mslmyilmaz5 (#15): RTX 3060 Ti 8 ГБ, Ubuntu 24.04 Docker,
CUDA 12.8.1 (подробности в [docs/linux.md](docs/linux.md)). Отчёты с других видеокарт ждём в [Discussions](https://github.com/alexturkey/voxcpm2-turkce-ses-tasarimi/discussions).

**AMD / Intel (экспериментально):** отдельный zip движка Vulkan (`...-win64-vulkan.zip`, без CUDA) устанавливается командой
`scripts\kur.ps1 -Kok C:\vox -Vulkan`. Он проверен только на нашей карте NVIDIA через бэкенд Vulkan (там он работал
медленнее CUDA, но при том же сиде давал тот же звук; этот замер сделан, когда диск был занят другой задачей, так что
чистое сравнение скорости ещё впереди), и на железе AMD или Intel мы его сами **не** тестировали: если попробуете,
пожалуйста, опубликуйте результат в Discussions. Если устройств Vulkan несколько (встроенное + дискретное), установщик
записывает индекс дискретной видеокарты как `cihaz` в `ayarlar.json`.

**Примечание:** поддержка Vulkan пока экспериментальная. Она успешно собрана и протестирована на GTX 1050 Ti. Кроме того, сторонний пользователь (mitra_tr) сообщил, что запускал её на AMD 6900 XT. На картах AMD/Intel нужно более широкое тестирование.

### Альтернатива: сборка движка из исходников

Нужны Visual Studio 2022 Build Tools с «Desktop development with C++» (вкл. C++ CMake tools), ~7 ГБ. Затем:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File scripts\kur.ps1 -Kok C:\vox -Derle
```
Команда также скачивает nvcc, загружает исходники audio.cpp v0.7.2, применяет `patches/0001-voxcpm2-4gb-ve-hiz.patch` и
собирает под вашу видеокарту (`-Mimari native` по умолчанию; или, например, `-Mimari 61`), ~15-25 мин. Корень должен быть коротким (`C:\vox`):
nvcc падает на длинных путях. Пошагово с проверками: [AGENTS.md](AGENTS.md).

### Частые проблемы при установке

| Что вы видите | Что это значит и что делать |
|---|---|
| `cudart64_12.dll not found` после двойного щелчка по exe | Движок не предназначен для ручного запуска. Выполните команду `kur.ps1` выше, затем запустите веб-интерфейс. |
| `64-bit Python 3.10+ bulunamadı` (Python не найден) | Установите Python (`winget install Python.Python.3.12`), закройте PowerShell, откройте новое окно и выполните ту же команду ещё раз. |
| `motor ekran kartını görmedi` (движок не увидел видеокарту) | Обновите драйвер NVIDIA до версии 570 или новее; проверьте, что `nvidia-smi` запускается. |
| `indirme başarısız` / `sha256 tutmadı` (загрузка не удалась / контрольная сумма не совпала) | Обычно это прерванная загрузка. Выполните ту же команду ещё раз; проверенные файлы пропускаются. |
| Сборка: `nvcc` падает | Сделайте корень установки коротким (`-Kok C:\vox`). |
| Страница не открывается | Запустите интерфейс через `baslat.bat` или откройте http://127.0.0.1:8765/ сами. Порт занят? Измените `"port"` в `ayarlar.json`. |

## Использование

Командная строка:
```powershell
# list voices
.venv\Scripts\python.exe -m ses_tasarim.oku --liste
# read with a bundled voice (one sentence per line; blank line or "|| paragraf" = longer pause, "|| 0,8" = 0.8 s)
.venv\Scripts\python.exe -m ses_tasarim.oku --ses hazir/belgesel_hanim --metin @metin.txt --cikti cikti\deneme
# design a new voice: 3 variants, 3 seeds
.venv\Scripts\python.exe -m ses_tasarim.tasarla --ad deniz_feneri --cesit 3 --tarif "A calm Turkish woman ..." --metin @tanitim.txt
# read with variant 2 of it
.venv\Scripts\python.exe -m ses_tasarim.oku --ses deniz_feneri/2 --metin @metin.txt --cikti cikti\deniz
# design, then read a text with each variant's lasting voice (dinleme.wav in each variant folder)
.venv\Scripts\python.exe -m ses_tasarim.tasarla --ad deniz_feneri --cesit 3 --tarif "A calm Turkish woman ..." --metin @tanitim.txt --dinleme @metin.txt
```
Правила текста: числа пишите словами, без кавычек (инструмент отклоняет цифры и кавычки), одно предложение на строку,
≤ 2000 символов в строке. Пауза после строки: `|| bagli` 0,25 с, `|| normal` 0,5 с, `|| paragraf` 1 с, `|| agir` 1,5 с
или своя длительность `|| 0,8` (0-5 с; цифры в этой метке разрешены). `ayarlar/okunus_sozlugu.tsv` исправляет произношение иностранных слов в турецком тексте.
Язык определяется по тексту (турецкие буквы, письменность, частые слова; при сомнении `dil` из карточки голоса; `--dil <code>` необязателен). В нетурецком тексте апострофы разрешены, турецкий словарь
пропускается, цифры по-прежнему отклоняются. Если при чтении выводится `speed gate: satır [...]`, прослушайте эти строки.

### Веб-интерфейс

Только локально (127.0.0.1): `.venv\Scripts\python.exe -m ses_tasarim.arayuz` → откройте http://127.0.0.1:8765/ сами
(другой порт: `--port 8800`) или дважды щёлкните `baslat.bat`. Остановить сервер: Ctrl+C. Три вкладки: *Создать голос*,
*Прочитать этим голосом*, *Клонирование голоса*. Обычный путь: *Создать* → прослушать варианты → *В мой список чтения* →
*Прочитать этим голосом* → скачать. Или выберите готовый голос в меню голосов и читайте.

- **Версия в шапке.** Мелкая бледная надпись `v0.2.0 · <short commit>` (с `+`, если в отслеживаемых файлах есть
  незакоммиченные изменения; без git только версия), чтобы на скриншотах и в видео было видно, какая версия использовалась.
- **Два голоса на каждой карточке варианта.** Сверху, серым, *Черновой голос дизайна*: он создаётся один раз и больше
  точно так же не прозвучит. Под ним, в оранжевой рамке, *↻ Этот голос вы будете слышать всегда*: запись дизайна, прочитанная
  заново как референс с собственным сидом варианта (он указан на карточке). Так голос звучит во всех последующих чтениях.
  Ниже кнопки *Прочитать этим голосом* и *В мой список чтения*. Одно нажатие *Создать* делает и то и другое: создаёт все
  варианты, затем читает ваш текст каждым постоянным голосом; одна полоса прогресса учитывает обе фазы. В папке варианта
  появляется `dinleme.wav`. Если это чтение прервётся, дизайн сохраняется, а на карточке появится пометка.
- **Окно «Текст, который хотите услышать».** На вкладке *Создать голос* поле *↻ Текст, который хотите услышать* содержит то, что
  прочитает каждый постоянный голос (если оставить его пустым, читается пример фразы). Щелчок по нему открывает тетрадь чтения в окне: номера
  строк, меню строки, полосы пауз. *Готово* записывает текст и паузы обратно в поле; *Отмена* или Esc ничего не меняют.
  У вкладки чтения свой текст.
- **Тетрадь чтения.** Одно предложение на строку. Щелчок по номеру строки открывает меню строки (вверх или вниз, переместить на
  позицию, дублировать, удалить; Alt+↑/↓, Alt+Shift+↓ или перетаскивание за номер; Ctrl+Z отменяет текст и паузы вместе).
  Щёлкните по тонкой полосе между двумя строками, чтобы выбрать паузу (bagli 0,25 · normal 0,5 · paragraf 1 · agir 1,5 с или
  своя от 0 до 5 с через шестерёнку); двойное Enter даёт абзац (1 с), а пустые строки становятся полосами пауз. Пока результат
  проигрывается, читаемая строка подсвечивается и прокручивается в поле зрения; *▶ Прослушать отсюда* в меню строки воспроизводит с этой строки.
  Текст и паузы сохраняются при перезагрузке страницы (хранилище браузера).
- **Черновики.** Кнопка *📄 Черновики* есть в обеих тетрадях (на вкладке чтения и в окне). Сохраните текущий текст с
  паузами как черновик, загрузите черновик одним щелчком (Ctrl+Z отменяет) и через ⋯ перезапишите, переименуйте или удалите его. Черновики
  хранятся в `sesler/taslaklar.json`, а не в репозитории.
- **Список чтения и меню голосов.** На карточке варианта кнопка *В мой список чтения* открывает поле имени: дайте варианту
  собственное имя, и ✓ добавит его. *Название генерации* остаётся у всех вариантов этого запуска. На вкладке *Прочитать этим голосом* кнопка
  голоса (флаг + имя) открывает меню голосов: сверху *Мой список чтения*, затем готовые голоса с флагами (сначала язык
  интерфейса). В каждой строке есть ▶ прослушать (постоянный голос, если он есть), сердечко (добавить или убрать) и ⋯; ↑/↓ и
  Enter выбирают, Esc закрывает, последний голос запоминается. Список хранится в `sesler/okuma_listesi.json`, вне
  репозитория, и сохраняется после перезапуска.
- **Управление голосами.** В меню ⋯ (строка меню голосов или карточка варианта) есть *Прочитать этим голосом*, добавить в список или убрать из него,
  *Переименовать* (пустое имя возвращает исходное; *Вернуть исходное имя*), *Удалить* для созданных голосов и *Скрыть*
  для готовых; оба действия сначала просят подтверждения. Удалённый голос переносится в `sesler/_cop/`; скрытие никогда не трогает файлы репозитория.
  Внизу меню голосов пункт *Скрытые и удалённые голоса (N)* содержит *Вернуть*. Собственные имена и скрытые голоса хранятся
  в `sesler/yerel_katman.json`. У переименованного голоса серым показано происхождение (*название генерации · вариант N*); ⋯ → *Перейти к
  генерации* открывает его дизайн.
- **Горячие клавиши и файлы.** Ctrl+Enter (⌘+Enter на Mac) запускает *Создать* или *Прочитать этим голосом* на открытой вкладке.
  Полоса прогресса показывает *прошло / ~всего*, с оценкой, выученной на предыдущих задачах на вашем компьютере. Скачанный файл называется
  по голосу и времени (`Voice_Name_2026-11-02_0152.wav`).

**Клонирование голоса (вашего собственного или с согласия владельца).** На вкладке *Клонирование голоса* загрузите свою запись (wav/mp3/flac/ogg, рекомендуется 5-30 с чистой речи; меньше 3 с отклоняется, больше 36 с обрезается), её точную расшифровку и текст для чтения. Кнопка остаётся неактивной, пока вы не отметите «Этот голос мой, или у меня есть явное разрешение владельца». Запись уходит только на локальный сервер (127.0.0.1), обрабатывается во временной папке вместе с её референсным кодированием, и эта папка удаляется по окончании задачи, в том числе при сбое; по сети ничего не отправляется. Сохраняется только синтетический результат (интерфейс: `sesler/_okumalar/<job>/`, CLI: `--cikti`). Результат: `klon_synthetic.wav` с пометкой «synthetic»; при публикации помечайте его как сгенерированный ИИ. CLI: `python -m ses_tasarim.klonla --kayit myvoice.wav --kayit-metni @transcript.txt --metin "Hello." --cikti out/clone --onay`

## Частые вопросы

**Модель или движок? Что есть что?** VoxCPM2 (OpenBMB) это *модель*: нейросеть на 2 миллиарда параметров, которая превращает
текст в речь. audio.cpp это *движок*: программа на C++/CUDA, которая запускает модель на вашей видеокарте (`audiocpp_cli.exe`). Наш
патч меняет движок, а не модель: он позволяет VoxCPM2 поместиться в 4 ГБ и делает так, что одинаковый сид каждый раз даёт
одинаковый звук. Пакет Python в этом репозитории только готовит текст, вызывает движок и собирает файлы.

**Какие видеокарты?** См. «Поддерживаемые видеокарты» выше: NVIDIA начиная с GTX 10xx, от 4 ГБ VRAM, драйвер ≥ 570. В релизе есть
нативный код для sm_61/75/86/89/120a; другие карты Pascal и новее используют встроенный PTX (первый запуск медленнее). AMD/Intel:
экспериментальный zip Vulkan, `kur.ps1 -Vulkan`; сторонний пользователь сообщил, что запускал его на AMD 6900 XT, но более широкое
тестирование на AMD/Intel ещё нужно (см. «AMD / Intel» выше). Режим только на CPU (`"backend": "cpu"` в `ayarlar.json`) работает, но
~6× медленнее GTX 1050 Ti (замер движка: 535 с против 94 с на 48 с речи); этот путь не поддерживается.

**Насколько быстро?** Замер на GTX 1050 Ti 4 ГБ (i7-7700HQ): один вариант дизайна (запись ≈ 25 с) 55 с; чтение ≈ 2 с
вычислений на 1 с речи (коэффициент реального времени 1,9-2,8) после однократного кодирования референса ~50 с на голос (кешируется
на диске) и 10-20 с загрузки модели на пакет; пик VRAM 2,6-2,9 ГБ. Новые видеокарты быстрее; цифры и методика:
[docs/4gb.md](docs/4gb.md).

**Может ли он клонировать голос?** Лежащая в основе модель VoxCPM2 умеет имитировать голос по референсной записи, и раздел
клонирования этим пользуется. Используйте его только со своим голосом или с явного разрешения человека, которому голос принадлежит;
интерфейс просит подтвердить это разрешение. Для дизайна голоса запись не нужна: он начинается с текстового описания на английском или китайском, а
«референс», используемый для чтения созданным голосом, это собственная синтетическая запись дизайна, сделанная моделью. Выдача себя за другого,
мошенничество и обман запрещены. См. [ETHICS.md](ETHICS.md). Помечайте опубликованное как сгенерированное ИИ.

**Как написать хорошее описание голоса?** По-английски, 1-3 предложения: возраст и пол, тембр (глубокий/звонкий, тёплый,
гнусавый, хриплый), тон и роль (спокойный диктор документального кино, энергичный ведущий), темп (медленный, размеренный) и
«clean studio recording, no background noise». Пишите описание, а не сценарий; без скобок. Запросите 3-5
вариантов и прослушайте: сид сильно меняет голос. Для текста создания возьмите 1-2 естественных предложения на языке голоса, в
нужном настроении (не больше ~20 с речи). При чтении одно предложение на строку; длинные предложения разбивайте, числа пишите словами.
